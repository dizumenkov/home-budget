# Домашний бюджет

Локальное Flask-приложение для учёта чеков:

- читает чеки из очереди Yandex Message Queue;
- запрашивает детальные данные чеков на proverkacheka.com;
- ведёт справочник товаров (`goods`), справочник сырых наименований (`products`), категории и метки;
- строит отчёты по суммам и периодам.

## Возможности

- **Загрузка чеков** из YMQ (по расписанию и по кнопке).
- **Запрос данных ФНС** по каждому чеку с учётом суточного лимита.
- **Ручной ввод** чеков (без обращения к ФНС).
- **Справочник товаров** — ручное ведение, редактирование, удаление с переназначением.
- **Сопоставление** сырых наименований (`products`) с продуктами (`goods`) — инлайн и через модалку.
- **Категории и метки** — иерархия (папки/элементы), установка соответствий «товар × категория».
- **Отчёты**:
  - `/analysis` — анализ по одной категории: круговая, столбчатая, квадратная (treemap) диаграммы, drill-down по подкатегориям, режим расчета процента (от общей / от группы);
  - `/compare-periods` — сравнение двух периодов (текущий vs базовый) с диаграммой и Δ/Δ%;
  - `/periods-analysis` — разбивка одной категории по интервалам (день/неделя/месяц/квартал/год), столбцы-интервалы кликабельны, ведут в `/analysis` с периодом этого интервала.
- **Настройки** `/settings` — редактирование `config.json` из браузера + QR с параметрами подключения к очереди.

## Требования

- Python 3.11+ (используется `zoneinfo`).
- SQLite (входит в стандартную библиотеку Python).
- `curl` и `xdg-open` (или аналог) — для `run.sh`.
- Интернет только для скачивания двух статических библиотек при установке (см. ниже). Дальше всё работает офлайн.

## Установка

```bash
git clone https://github.com/dizumenkov/home-budget.git
cd home-budget

python3 -m venv .venv
. .venv/bin/activate           # Windows: .venv\Scripts\activate

pip install -r requirements.txt


mkdir -p static

# Chart.js — для диаграмм на /analysis, /compare-periods, /periods-analysis
curl -fsSL -o static/chart.umd.min.js \
  https://cdn.jsdelivr.net/npm/chart.js@4.4.1/dist/chart.umd.min.js

# qrcodejs — для кнопки «Показать QR» на /settings
curl -fsSL -o static/qrcode.min.js \
  https://cdn.jsdelivr.net/gh/davidshimjs/qrcodejs@master/qrcode.min.js
